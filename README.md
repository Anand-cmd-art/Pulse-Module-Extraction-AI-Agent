# Pulse - Module Extraction AI Agent

## Overview

This project is an **Agentic AI application** designed to automatically "understand" product documentation. It crawls help center websites, filters out noise (headers, footers, navigation), and uses a Large Language Model (Google Gemma-3-27b via OpenRouter) to extract a structured hierarchy of **Modules** and **Submodules**.

**Assignment:** Pulse - Module Extraction AI Agent  
**Goal:** Transform unstructured documentation URLs into structured JSON hierarchies

### to activate the vnv

```bash
source venv/bin/activate
```
### to run the app

```bash
streamlit run app.py
```
